3-Stamp Mail даёт скриптам AutoJs6 глобальный объект `mail`: отправка писем, поиск и чтение сообщений, загрузка вложений, управление флагами и папками и наблюдение за новой почтой по IMAP, POP3 и SMTP. Учётные записи можно сохранить в плагине, а скрипты подключаются к ним по псевдониму.

### Начало работы

1. Включите IMAP или POP3 и SMTP в веб-настройках почтового сервиса и получите код авторизации (QQ, 163, 126, Sina) или пароль приложения (Gmail, iCloud, Yahoo); сам пароль для входа обычно не принимается.
2. Откройте 3-Stamp Mail из лаунчера, на странице "Сохранённые учётные записи" нажмите "Добавить учётную запись", выберите "Провайдер", введите адрес, "Псевдоним" и код авторизации, затем сохраните.
3. Нажмите кнопку меню рядом с учётной записью и выберите "Проверить подключение", чтобы убедиться, что серверы доступны.
4. Подключитесь к учётной записи в скрипте AutoJs6 через `mail.connect('alias')`, как показано ниже.

### Основные возможности

- **Отправка и управление**: отправка писем с вложениями, поиск по теме, дате и другим условиям, чтение текста, загрузка вложений, отметка прочитанного и управление папками.
- **Вход через браузер**: для учётных записей Gmail, Outlook.com и Microsoft 365 выберите в поле "Аутентификация" вариант "Войти через Google (браузер)" или "Войти через Microsoft (браузер)", войдите в браузере и сохраните; код авторизации не нужен.
- **Фоновые наблюдатели**: в разделе "Настройки" > "Фоновые наблюдатели" нажмите "Добавить наблюдателя" и выберите учётную запись и папку, и плагин будет держать её подключённой, даже когда скрипты не запущены. Затем в AutoJs6 долго нажмите на скрипт, выберите "Задача по расписанию" и в разделе "Задача по широковещательному событию" выберите "При получении письма (фоновое наблюдение почтового плагина)"; после этого скрипт запускается при каждом новом письме.
- **Безопасность учётных записей**: пароли и токены хранятся в плагине в зашифрованном виде; скрипты подключаются по псевдониму и не видят их.

### Использование в скриптах

В скриптах AutoJs6 глобальный объект `mail` доступен сразу, без импорта. Пример подключается к сохранённой учётной записи по псевдониму, отправляет письмо, читает непрочитанные письма и наблюдает за входящими:

```js
let client = mail.connect('work');

client.send({ to: 'you@example.com', subject: 'Report', text: 'See the attachment', attachments: ['/sdcard/report.xlsx'] });

client.fetch({ unseenOnly: true, limit: 10 }).forEach(m => {
    console.log(m.subject);
    client.markRead(m);
});

let watch = client.watch('INBOX', { fetchBody: true });
watch.on('message', m => console.log(m.subject, m.text));
```

- Можно не сохранять учётную запись, а передать данные напрямую, например `mail.connect({ provider: 'qq', address: 'me@qq.com', password: 'authorization-code' })`. У каждого сетевого метода есть вариант Async, который возвращает Promise.
- Скрипты Node.js загружают его через `require('autojs6:mail')`, а скрипты Bun используют `host.mail`, для которого нужно отдельное разрешение `mail.control`; все вызовы возвращают Promise.
- Скрипт, запущенный фоновым наблюдателем, читает пришедшее письмо из `engines.myEngine().execArgv.mail`.

### Требования

- Android 7.0 или новее, AutoJs6 6.8.0 или новее, и этот плагин включён в разделе "Центр плагинов".
- Для запуска скриптов при новой почте нужна версия AutoJs6 с поддержкой фоновых наблюдателей; если ваша её не поддерживает, это видно на странице "Фоновые наблюдатели".
- Разрешение на сеть используется только для подключения к настроенным вами почтовым серверам и, при входе через браузер, для получения и продления токенов у Google или Microsoft.
- Упакованные приложения с собственной подписью могут использовать только данные учётной записи, переданные скриптом; сохранённые учётные записи и фоновые наблюдатели доступны только AutoJs6.

### Частые вопросы

**При подключении возникает ошибка аутентификации**

Большинство почтовых сервисов не принимают пароль для входа. Проверьте, что IMAP или POP3 и SMTP включены в веб-настройках сервиса, используйте код авторизации или пароль приложения и проверьте через "Проверить подключение".

**Наблюдение прекращается после выключения экрана**

Android через некоторое время после выключения экрана замораживает сеть фоновых приложений. Запросите исключение для плагина в разделе "Настройки" > "Оптимизация батареи", чтобы оставаться на связи; этот шаг необязателен.

**Скрипт сообщает, что плагин отсутствует**

Убедитесь, что плагин установлен и включён в разделе "Центр плагинов" AutoJs6, затем снова запустите скрипт; перезапускать AutoJs6 не нужно.

Все методы и параметры описаны в [документации AutoJs6 > Mail](https://docs.autojs6.com/#/mail), настройка почтовых сервисов и другие сведения - на [странице проекта](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stamp-Mail).
