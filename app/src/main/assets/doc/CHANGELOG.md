******

### 发行历史

******

# v1.2.1

###### 2026/09/22

* `修复` 会话关闭时守望的 `closed` 事件原因固定为 `closed` (此前工作线程可能先以 `session-closed` 停掉部分守望)
* `优化` 发布版本同时带有 Google OAuth 2.0 客户端 ID, Gmail 预设提供浏览器登录 (Google 项目通过敏感权限审核前仅限项目测试用户登录, 且刷新令牌 7 天过期后需重新登录), 访问令牌与应用专用密码方式不变

# v1.2.0

###### 2026/09/22

* `提示` 浏览器登录需要构建时配置对应服务商的 OAuth 2.0 客户端 ID, 未配置时仍可使用访问令牌或应用专用密码 (Google 客户端通过敏感权限审核前仅限项目测试用户登录)
* `新增` Gmail, Outlook.com 及 Microsoft 365 账户支持通过浏览器登录, 使用 OAuth 2.0 授权码流程及 PKCE 校验, 并自动填入邮箱地址
* `新增` 浏览器登录的令牌支持加密保存及自动续期, mail.accounts.list 可查询授权状态, 续期被拒时提示重新登录
* `新增` 账户页增加 "重新登录" 及 "撤销登录" 操作, 撤销后账户停止工作, Google 账户同时请求撤销刷新令牌

# v1.1.0

###### 2026/09/21

* `提示` 后台守望唤醒 "邮件到达时" 任务需要支持邮件契约版本 2 的 AutoJs6 6.8.0 构建 (5282 之后), 旧版宿主仅记录新邮件; 守望使用前台服务及通知权限, 开机自启默认关闭 (权限说明参阅 README)
* `新增` 后台守望页面, 支持为已保存账户配置最多 16 个守望, 无脚本运行时仍可通过 IDLE 或轮询监听新邮件, 断线后自动重连, 保留最近 100 条邮件摘要并支持开机自启 (默认关闭)
* `新增` 后台守望支持唤醒 AutoJs6 的 "邮件到达时" 任务, 宿主可订阅连接状态及邮件事件并更新筛选条件 (每个守望最多 4 个订阅者)
* `新增` 后台守望支持按发件人及主题进行不区分大小写的子串筛选, 文件夹打开后显示已连接状态, 宿主每项任务的最短触发间隔为 3 s

# v1.0.1

###### 2026/09/21

* `修复` Outlook.com 及 Microsoft 365 的 POP3 账户使用 OAuth 2.0 令牌登录时出现 AUTH_FAILED 的问题, 兼容 Microsoft 服务器的两步 XOAUTH2 认证
* `优化` 补充 Outlook.com 的 OAuth 2.0 兼容性说明, 包含服务器保存已发送副本, 中文搜索延迟及不保留自定义关键字等差异 (部分个人邮箱可能被服务器拒绝 SMTP 登录)

# v1.0.0

###### 2026/09/19

* `提示` 需要 AutoJs6 6.8.0 (构建 5282) 或更高版本
* `新增` mail 插件服务, 用于向宿主提供插件信息, 能力, 服务商预设, 已保存账户及邮件会话
* `新增` 基于 Eclipse Angus Mail 的邮件核心, 支持 IMAP/POP3/SMTP, SSL/STARTTLS 及密码/XOAUTH2 认证
* `新增` Gmail/Outlook.com/Microsoft 365/QQ/163/126/iCloud/Yahoo/Sina/Aliyun 服务商预设, 支持连接测试, 超时配置, 断线重连及脱敏的协议调试摘要
* `新增` mail.send 支持收件人/抄送/密送, 文本及 HTML 正文, 附件, 内联图片和回复信息, 可按服务商行为保存已发送副本, messages.append 支持写入草稿
* `新增` IMAP 文件夹管理及邮件分页, 搜索, 正文读取, 附件下载, 标记, 移动和删除, 支持客户端搜索回退及常见邮件字符集 (服务器不支持 UID EXPUNGE 时改用整夹 EXPUNGE)
* `新增` POP3 账户支持收件箱分页, 信头搜索, 正文及附件下载和删除, 搜索最多检查 200 封候选邮件 (不支持标记, 移动, 复制, 正文搜索及文件夹管理)
* `新增` 邮件会话支持排队, 取消及关闭, 取消可中断无响应的网络连接, 超出队列上限时返回 LIMIT_EXCEEDED (仅接受与插件同签名的 AutoJs6 宿主)
* `新增` 10 种语言的 README, 插件中心说明与更新日志
* `新增` 账户密码及访问令牌通过 Android Keystore 加密保存并排除备份, 账户别名支持 Unicode 规范化及不区分大小写的匹配
* `新增` mail.connect 支持通过账户别名连接, 凭据仅在插件进程内解密, 已保存账户列表仅返回账户信息及默认标记
* `新增` 账户设置页, 支持服务商预设, 自定义服务器, 连接测试, 默认账户及编辑/删除操作, 跟随宿主主题与语言 (编辑时密码留空可沿用已保存凭据)
* `新增` 宿主可通过插件设置入口打开账户页, 启动器也可独立打开 (宿主入口需要插件权限)
* `新增` 发行历史页面, 支持按当前语言显示及英文回退, 可从设置页或关于页打开 (更新检查由 AutoJs6 插件中心提供)
* `新增` 设置页增加电池优化状态及系统授权入口, 用于减少后台监听被暂停的情况 (仅由用户主动申请, 不作为功能前提)
* `新增` 新邮件监听支持 IMAP IDLE, 断线后自动重连, 服务器不支持或连续失败时回退轮询, 邮件去重上报, 会话关闭时停止监听
* `新增` 新邮件监听支持轮询, 默认间隔 60 s, 首轮仅建立快照, POP3 账户仅报告新增邮件且在轮询间隔内释放邮箱
* `新增` 宿主可订阅及停止新邮件监听, 网络变化时立即重连, 事件积压或数据过大时通过 resync 通知重新同步, 宿主退出时自动关闭监听
* `修复` 163 及 126 邮箱默认重复保存已发送邮件副本的问题
* `修复` AGP 9.1 构建时的 SDK XML v4 解析警告, 以及 JVM 单元测试误触发 APK 原生库对齐检查的问题 (共享构建插件 1.8.3)
* `修复` 部分系统关闭账户编辑器时弹出密码管理器保存提示的问题 (账户表单退出系统自动填充)
* `修复` QQ/Sina/163/126 邮箱自动监听模式无法及时收到新邮件的问题, 改为优先轮询, 设备退出 Doze 后立即重连 (显式指定 IDLE 时保留该模式)
* `修复` POP3 缺少 STLS 升级或握手前超时时被误报为 AUTH_FAILED 的问题, 分别返回 TLS_FAILED 或 TIMEOUT
* `修复` 字符集误声明为 US-ASCII/ISO-8859-1 的 UTF-8 或 GB18030 邮件出现乱码, 以及未声明编码的 ISO-2022-JP 邮件解码失败的问题 (Big5/EUC-KR 仍需声明字符集)
* `修复` POP3 XOAUTH2 登录被服务器拒绝时误报为可重试 IO_FAILED 的问题, 改为返回 AUTH_FAILED; 补充 QQ/163/126/yeah.net/Sina 的搜索及已发送副本限制 (QQ 中文搜索可使用 `fallback: 'always'`)
* `修复` 取消调用或停止监听后写超时线程未释放的问题
* `修复` Gmail 中文搜索被拒绝的问题, 改用 CHARSET UTF-8 并为客户端搜索提供进度; Outlook.com 禁用密码认证时返回 AUTH_MECHANISM_UNSUPPORTED (客户端正文搜索仍可能耗时较长)
* `优化` 账户未开启 POP 访问时返回带原因的 UNSUPPORTED_OPERATION, 避免误报为可重试的 IO_FAILED
* `优化` 补充 Sina 的已发送文件夹预设及限制说明, 文件夹需在网页端创建, 服务器不自动保存已发送副本; 更新 126 邮箱自动保存副本的说明
* `优化` 补充 Yahoo Mail 及 Aliyun Mail 预设的验证范围, 已发送副本行为依据公开文档, 尚未经真实账户核实
* `优化` 加强凭据保护及日志检查, 账户文档拒绝明文凭据, 异常与调试摘要隐藏敏感内容
* `优化` 限制超长信头, 收件人及 MIME 层级的处理开销, 单封异常邮件不再阻断整页列表, 损坏编码及 multipart 内容支持宽松解码或原样下载
* `优化` IMAP 分段抓取大小由 64 KiB 提升至 1 MiB, 减少大附件下载的网络往返, 客户端搜索达到结果上限后即停止 (长时间监听需要宿主保持前台服务)
* `优化` 精简邮件库的 R8 保留规则, 减小发行安装包体积
* `依赖` 附加 Eclipse Angus Mail 版本 2.0.5, Angus Activation 版本 2.0.3 及 Jakarta Activation API 版本 2.1.4
* `依赖` 附加 GreenMail 版本 2.1.13 (仅用于 JVM 测试)
* `依赖` 附加 common-plugin-api 本地模块, 用于共享插件契约 (来源: AutoJs6 6.8.0/5282, MPL 2.0, 锁定文件哈希)
* `依赖` 附加 mail-api 本地模块, 用于邮件契约 (来源: AutoJs6 6.8.0/5282, MPL 2.0, 锁定文件哈希)
